# qwgram Next

Новый клиент Telegram с нуля: Kotlin + Jetpack Compose + **Material 3 Expressive**, работает через официальную библиотеку **TDLib** на настоящих серверах Telegram.

## Сборка
Actions → **Build qwgram Next** → Run workflow. Нужны секреты репозитория `TG_APP_ID` и `TG_APP_HASH` (с my.telegram.org). Первая сборка дольше (собирается TDLib, потом кэшируется). APK — в артефакте `qwgram-next-apk`.

## Что есть
- Вход: телефон, код, пароль 2FA, регистрация, e-mail-код
- Чаты, папки (группа кнопок / вкладки / чипы), архив, поиск, контакты
- Сообщения: текст с форматированием и ссылками, ответы, пересылка, редактирование, удаление, реакции, закреп, черновики
- Медиа: фото (просмотр), видео, стикеры, голосовые (запись и проигрывание), музыка, файлы, гео, контакты, опросы
- Профили и медиа чата, уведомления в фоне
- Огромные настройки вида: тема/AMOLED/Material You/свой HEX, 26 форм аватарок с морфингом, список, пузыри, фон, панели, анимации, шрифт и масштаб
- Настройки Telegram: аккаунт, уведомления, конфиденциальность, устройства, память
- Функции qwgram: скрытие номера, тихая отправка, чтение без отметки, чистка трекинга из ссылок
