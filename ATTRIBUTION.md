Основа: <https://github.com/DrKLO/Telegram>, лицензия GPL v2 или новее. Собранный клиент является

## Inugram

Патчсет и инфраструктура сборки взяты из Inugram, <https://github.com/teidesu/inugram>,
автор alina sireneva, лицензия MIT. Текст лицензии с уведомлением об авторских правах лежит в `LICENSE`
и должен сохраняться во всех копиях. Исходный README автора: `README.inugram.md`,
исходное руководство для агентов: `docs/inugram-agent-guide.md`.

Что изменено относительно Inugram:
- идентификатор приложения `com.qwenz.zhirgram`;
- `api_id` и `api_hash` автора заменены на значения владельца этой сборки (подставляет CI из Secrets);
- упрощён CI (только вариант без плагинов, подпись debug-ключом).

Фирменные ключи, Firebase-проект, адреса обновлений и каналы Inugram принадлежат его автору.
См. список задач по замене в `AGENTS.md`.

Часть возможностей самого Inugram портирована им из Nekogram, NagramX и materialgram,
подробности и благодарности в `README.inugram.md` и `FEATURES.md`.
